## 测试结论

普通 Windows 摄像头测试只能证明 OpenCV 后端和上层 Camera 接口在该环境下的功能。只有连接实际海康相机并成功执行 MVS 后端测试后，才能填写“海康 MVS 硬件取图通过”。
