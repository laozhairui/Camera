## 10. 测试限制

当前测试使用 Windows 集成摄像头完成 OpenCV 后端验证。

由于开发阶段没有连接实际海康工业相机，因此 MVSBackend 未进行真实硬件取图测试。

MVS 后端代码按照海康 MVS SDK 生命周期设计完成，包括设备枚举、句柄创建、设备打开、开始取流、获取图像缓存以及资源释放流程。

只有连接实际海康工业相机后，才能进一步验证 MVS 硬件取图功能。
